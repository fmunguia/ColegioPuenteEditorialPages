Valor absoluto

📖 Valor absoluto
  • \(|x| = \begin{cases} x & \text{si } x \geq 0 \\ -x & \text{si } x < 0 \end{cases}\)
  • Es la distancia del número \(x\) al \(0\) en la recta real, por eso nunca es negativo: \(|5| = 5\), \(\ |-5| = 5\)
  • \(|a - b|\) es la distancia entre los números \(a\) y \(b\)
⚠️ El valor absoluto no se reparte en la suma

\(|a + b|\) no es \(|a| + |b|\): \(\ |3 + (-5)| = 2\), pero \(|3| + |-5| = 8\).

El valor absoluto permite escribir intervalos centrados en un punto, algo muy útil para expresar tolerancias y márgenes de error.

Ejemplo. Valor absoluto e intervalos
  • \(|x| < 3 \iff -3 < x < 3 \iff x \in (-3, 3)\)
  • \(|x - 5| \leq 2 \iff 3 \leq x \leq 7 \iff x \in [3, 7]\) (números a distancia de 5 como mucho 2)
  • \(|x| > 1 \iff x \in (-\infty, -1) \cup (1, +\infty)\)
