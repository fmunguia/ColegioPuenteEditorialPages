Apartado 9.7

Identidades y ecuaciones trigonométricas

Con las relaciones fundamentales y el cálculo algebraico podemos transformar expresiones trigonométricas: simplificarlas, comprobar que dos expresiones son iguales para cualquier ángulo y resolver ecuaciones en las que la incógnita es un ángulo.

Simplificación de expresiones

📖 Cómo simplificar una expresión trigonométrica
  1. Escribimos todas las razones en función del seno y del coseno: \(\ \tan \alpha = \dfrac{\sin \alpha}{\cos \alpha}\).

  2. Usamos la relación fundamental en la forma que convenga:

    \[\sin^2 \alpha + \cos^2 \alpha = 1 \qquad \sin^2 \alpha = 1 - \cos^2 \alpha \qquad \cos^2 \alpha = 1 - \sin^2 \alpha\]
  3. Operamos como con polinomios y fracciones algebraicas: factor común, identidades notables y simplificación de factores.
Ejemplo. Simplificación
  • \(\dfrac{1 - \cos^2 \alpha}{\sin \alpha \cos \alpha} = \dfrac{\sin^2 \alpha}{\sin \alpha \cos \alpha} = \dfrac{\sin \alpha}{\cos \alpha} = \tan \alpha\)
  • \(\sin^3 \alpha + \sin \alpha \cos^2 \alpha = \sin \alpha \left(\sin^2 \alpha + \cos^2 \alpha\right) = \sin \alpha\)
  • \(\dfrac{\cos^2 \alpha}{1 - \sin \alpha} = \dfrac{1 - \sin^2 \alpha}{1 - \sin \alpha} = \dfrac{(1 + \sin \alpha)(1 - \sin \alpha)}{1 - \sin \alpha} = 1 + \sin \alpha\)

  3. \((\sin \alpha + \cos \alpha)^2 + (\sin \alpha - \cos \alpha)^2\)

Demostración de igualdades

Una identidad trigonométrica es una igualdad que se cumple para todos los ángulos en los que sus dos miembros tienen sentido, como \(\sin^2 \alpha + \cos^2 \alpha = 1\).

📖 Cómo demostrar una igualdad
  • Partimos de uno de los miembros, normalmente el más complicado, y lo transformamos con las relaciones fundamentales hasta llegar al otro.
  • O bien transformamos los dos miembros por separado hasta llegar a la misma expresión.

No se pasan términos de un miembro a otro como en una ecuación: eso sería dar por cierto lo que queremos demostrar.

Ejemplo. Demostración

  • Demuestra que \(\ \tan \alpha + \dfrac{1}{\tan \alpha} = \dfrac{1}{\sin \alpha \cos \alpha}\).

    \[\tan \alpha + \dfrac{1}{\tan \alpha} = \dfrac{\sin \alpha}{\cos \alpha} + \dfrac{\cos \alpha}{\sin \alpha} = \dfrac{\sin^2 \alpha + \cos^2 \alpha}{\sin \alpha \cos \alpha} = \dfrac{1}{\sin \alpha \cos \alpha}\]

  • Demuestra que \(\ \dfrac{\cos \alpha}{1 - \sin \alpha} = \dfrac{1 + \sin \alpha}{\cos \alpha}\). Multiplicamos arriba y abajo por \(1 + \sin \alpha\):

    \[\dfrac{\cos \alpha \,(1 + \sin \alpha)}{(1 - \sin \alpha)(1 + \sin \alpha)} = \dfrac{\cos \alpha \,(1 + \sin \alpha)}{1 - \sin^2 \alpha} = \dfrac{\cos \alpha \,(1 + \sin \alpha)}{\cos^2 \alpha} = \dfrac{1 + \sin \alpha}{\cos \alpha}\]
⚠️ Comprobar con un ángulo no es demostrar

Que la igualdad se cumpla para \(30^\circ\) o para \(45^\circ\) no prueba que se cumpla para todos los ángulos. En cambio, basta un ángulo en el que falle para saber que no es una identidad: \(\sin \alpha + \cos \alpha = 1\) es cierta para \(0^\circ\), pero para \(45^\circ\) da \(\sqrt{2} \neq 1\).

Ecuaciones trigonométricas

En una ecuación trigonométrica la incógnita es un ángulo que aparece dentro de una razón trigonométrica. Como las razones se repiten cada vuelta, si hay solución hay infinitas: se buscan las que están entre \(0^\circ\) y \(360^\circ\) y se les suman vueltas completas, \(360^\circ k\) con \(k\) entero.

📖 Cómo resolver una ecuación trigonométrica
  1. Con las relaciones fundamentales dejamos una sola razón, o factorizamos.
  2. Despejamos hasta llegar a \(\sin x = a\), \(\cos x = a\) o \(\tan x = a\). Si \(a > 1\) o \(a < -1\), el seno y el coseno no tienen solución.

  3. Buscamos el ángulo agudo \(\alpha\) con esa razón (sin el signo) y, con los signos de los cuadrantes, las soluciones entre \(0^\circ\) y \(360^\circ\):

    \(\sin x = a\)\(\cos x = a\)\(\tan x = a\)
    \(x\) y \(180^\circ - x\)\(x\) y \(360^\circ - x\)\(x\) y \(180^\circ + x\)
  4. Añadimos las vueltas: \(x = x_1 + 360^\circ k\), \(x = x_2 + 360^\circ k\).
Ejemplo. Ecuaciones con una razón
  • \(2 \sin x - 1 = 0 \Rightarrow \sin x = \dfrac{1}{2}\). El seno es positivo en I y II: \(\ x = 30^\circ + 360^\circ k\), \(x = 150^\circ + 360^\circ k\).
  • \(2 \cos^2 x - 1 = 0 \Rightarrow \cos x = \pm \dfrac{\sqrt{2}}{2}\). Hay cuatro soluciones en una vuelta: \(45^\circ\), \(135^\circ\), \(225^\circ\) y \(315^\circ\).
  • \(\cos x = -0{,}4\). La calculadora da \(\cos^{-1}(-0{,}4) \approx 113{,}58^\circ\); la otra solución es \(360^\circ - 113{,}58^\circ = 246{,}42^\circ\).
Ejemplo. Factorizar o cambiar de razón
  • \(\sin^2 x - \sin x = 0 \Rightarrow \sin x \,(\sin x - 1) = 0\). Si \(\sin x = 0\): \(x = 0^\circ\) o \(x = 180^\circ\). Si \(\sin x = 1\): \(x = 90^\circ\).

  • \(2 \cos^2 x + \sin x = 1\). Cambiamos \(\cos^2 x = 1 - \sin^2 x\): \(\ 2 - 2\sin^2 x + \sin x = 1 \Rightarrow 2 \sin^2 x - \sin x - 1 = 0\). Es una ecuación de segundo grado en \(\sin x\):

    \[\sin x = \dfrac{1 \pm \sqrt{1 + 8}}{4} = \begin{cases} 1 & \Rightarrow x = 90^\circ \\ -\dfrac{1}{2} & \Rightarrow x = 210^\circ, \ x = 330^\circ \end{cases}\]
⚠️ No dividas entre una razón trigonométrica

En \(\sin^2 x = \sin x\), si dividimos entre \(\sin x\) queda \(\sin x = 1\) y perdemos las soluciones de \(\sin x = 0\), es decir, \(0^\circ\) y \(180^\circ\). Hay que pasar todo a un miembro y sacar factor común.
