Una plantilla es un modelo de documento con el diseño, los textos fijos y las fórmulas ya hechos. Al abrirla se crea un libro nuevo, y la plantilla queda sin tocar. Se guarda con Archivo › Guardar como › Plantilla de Excel (*.xltx). En Archivo › Nuevo hay plantillas de facturas, presupuestos o calendarios.

Una macro es una serie de acciones que Excel graba y después repite con un clic o un atajo de teclado. Sirve para tareas repetitivas: dar el mismo formato a un informe, borrar los datos de una factura para empezar otra…

⚠️ ¡Ojo!

Un libro con macros se guarda como Libro de Excel habilitado para macros (*.xlsm). Si lo guardas como .xlsx, las macros se pierden. Y no actives las macros de archivos que no conozcas: pueden llevar virus.

Excel trabaja con datos de otros programas (importar) y los entrega en otros formatos (exportar):

FormatoQué esCómo
CSVTexto con los datos separados por punto y coma. Lo usan muchos programas de gestión y bancos.Importar: Datos › Obtener datos › De texto/CSV.
PDFDocumento que no se puede modificar. Para enviar facturas y presupuestos.Archivo › Exportar › Crear PDF/XPS.
ODSHoja de cálculo de LibreOffice Calc.Guardar como › Hoja de cálculo OpenDocument.
WordUna tabla o un gráfico dentro de un documento.Copiar y Pegado especial › Vincular.

En una oficina, varias personas trabajan en el mismo libro. Si se guarda en OneDrive o SharePoint y se pulsa Compartir, pueden editarlo a la vez (coautoría): ves dónde está cada uno. Con Revisar › Nuevo comentario dejas preguntas a los compañeros, y en Archivo › Información › Historial de versiones recuperas una versión anterior.

Las macros se guardan en un lenguaje de programación, VBA (Visual Basic para Aplicaciones). En la pestaña Programador › Visual Basic puedes ver el código de tu macro: cada acción que grabaste es una línea.
