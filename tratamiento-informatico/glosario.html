🔤 Glosario

agenda electrónica
calendario y lista de tareas digitales que avisan y se sincronizan entre dispositivos
ajuste del texto
forma en que el texto rodea a una imagen o forma
animación
efecto de un objeto dentro de la diapositiva: entrada, énfasis, salida o trayectoria
archivo
conjunto de datos guardado con un nombre y una extensión
base de datos
conjunto organizado de datos relacionados entre sí
bit
unidad mínima de información: un 0 o un 1
borde
línea que rodea un texto, un párrafo o una página
BUSCARV
función que busca un dato en la primera columna de una tabla y devuelve el valor de otra columna de la misma fila
byte
grupo de 8 bits; equivale a un carácter
campo
columna de una tabla: un dato concreto de cada elemento
capas
imágenes superpuestas que se editan por separado, como acetatos
celda
cuadro donde se cruzan una columna y una fila; se nombra con su letra y su número
clave principal
campo que identifica cada registro y no se puede repetir
columnas
reparto del texto en varias franjas verticales, como en un periódico
Combinar correspondencia
función que crea muchas cartas, sobres o etiquetas iguales con los datos de cada destinatario
compresión
reducción del tamaño de un archivo; con pérdida, se elimina información
consulta
pregunta a la base de datos que muestra solo los datos que cumplen unas condiciones
control de cambios
función que marca en color todo lo que se añade o se borra en un documento
controlador
pequeño programa que explica al sistema operativo cómo usar un periférico
controlador de relleno
cuadrito de la esquina inferior derecha de la celda activa; al arrastrarlo copia la fórmula o sigue una serie
códec
programa que comprime y descomprime el vídeo o el audio
CPU
unidad central de procesamiento o procesador; interpreta y ejecuta las instrucciones
dato personal
cualquier información que identifica a una persona o permite identificarla
encabezado
zona superior de la página que se repite en todas las páginas
ergonomía
adaptación del puesto de trabajo a la persona para trabajar cómoda y sin lesiones
Escribir al tacto
escribir con los diez dedos sin mirar el teclado
estilo
conjunto de formatos con un nombre que se aplica de una vez
extensión
letras tras el punto del nombre de un archivo que indican su tipo
fila guía
fila central del teclado donde descansan los dedos: ASDF y JKLÑ
firma
bloque de texto con los datos de quien escribe, que se añade al final de los correos
formato condicional
formato que se aplica solo a las celdas que cumplen una condición
formato contenedor
tipo de archivo de vídeo que guarda juntas las pistas de vídeo, audio y subtítulos
formato de fuente
aspecto de las letras: tipo de letra, tamaño, estilo, color y efectos
formulario
pantalla para ver e introducir los datos de una tabla registro a registro
fotogramas
cada una de las imágenes que forman un vídeo
fórmula
cálculo que se escribe en una celda; empieza siempre por el signo igual
función
fórmula que ya trae Excel; tiene un nombre y unos argumentos entre paréntesis
función SI
función que comprueba una condición y da un resultado si es verdadera y otro si es falsa
gestor de contraseñas
programa que guarda todas las contraseñas cifradas bajo una sola contraseña maestra
gráfico
dibujo que representa los datos de una tabla para verlos y compararlos de un vistazo
guion gráfico
secuencia de dibujos que muestra los planos de un vídeo antes de grabarlo
hardware
parte física del ordenador: lo que se puede ver y tocar
hoja de cálculo
programa que organiza datos en filas y columnas y hace cálculos con ellos
informe
presentación de los datos preparada para imprimir, con grupos y totales
ingeniería social
técnicas para engañar a una persona y conseguir que dé datos o haga algo que no debe
integridad referencial
regla que impide tener registros relacionados con otros que no existen
letra capital
primera letra de un párrafo, grande y ocupando varias líneas
libreta de direcciones
lista de contactos con sus datos: correo, teléfono, empresa
libro
archivo de Excel; contiene una o varias hojas
licencia
permiso del autor para usar un programa, con sus condiciones
línea de tiempo
zona del editor donde se colocan y ordenan los clips, textos y sonidos
macro
serie de acciones grabadas que Excel repite al pulsar un botón o un atajo
malware
programa malicioso que se instala sin permiso para dañar el equipo, robar datos o pedir dinero
mapas de bits
imágenes formadas por una cuadrícula de píxeles
marca de agua
texto o imagen clara detrás del texto de todas las páginas
márgenes
espacio en blanco entre el borde del papel y el texto
memoria secundaria
almacenamiento permanente: discos duros HDD y SSD
nota al pie
aclaración que se numera en el texto y se escribe al final de la página
parte de incidencias
documento que registra un problema informático, su causa y su solución
patrón de diapositivas
diapositiva principal que controla el diseño, las fuentes, los colores y el logo de todas las demás
párrafo
texto que va desde el principio hasta que se pulsa Intro; Word lo marca con el signo ¶
periféricos
dispositivos que se conectan al ordenador para meter o sacar información
phishing
engaño que suplanta a una empresa o persona de confianza para robar contraseñas o datos
pie de página
zona inferior de la página que se repite en todas las páginas
píxel
cada uno de los puntos de color que forman una imagen digital
placa base
circuito principal al que se conectan todos los componentes del ordenador
plantilla
documento modelo (.dotx) del que se crean documentos nuevos sin modificar el original
presentación
conjunto de diapositivas que apoyan lo que cuenta una persona en público
procesador de textos
programa para escribir, corregir, dar formato e imprimir documentos
pulsaciones por minuto
número de teclas pulsadas en un minuto (ppm); cada letra, espacio o signo cuenta una
RAM
memoria principal de trabajo; es volátil: se borra al apagar
rango
grupo de celdas seguidas; se escribe con la primera y la última celda separadas por dos puntos
referencia absoluta
referencia a una celda que no cambia al copiar la fórmula; lleva el signo $ delante de la columna y de la fila, como $F$1
referencia relativa
referencia a una celda que cambia al copiar la fórmula, como B2
registro
fila de una tabla: todos los datos de un elemento
regla
instrucción que hace que el programa trate solo los correos que cumplen una condición
relacional
base de datos con varias tablas unidas por campos comunes
requisitos
características mínimas o recomendadas que debe tener un equipo para que una aplicación funcione
resolución
número de píxeles por pulgada (ppp) al imprimir una imagen
salto de página
marca que obliga a empezar una página nueva
sangría
distancia entre el margen de la página y el texto de un párrafo
serie
lista de datos que siguen un orden (días, meses, números, fechas) y que Excel completa sola
sistema informático
conjunto de hardware, software y personas que trabajan con información
sistema operativo
programa principal que gestiona el hardware y el software y permite usar el ordenador
software
parte lógica del ordenador: programas y datos
sombreado
color de fondo de un texto o de un párrafo
tabla
cuadrícula de filas y columnas para ordenar datos
tabla dinámica
resumen de una lista de datos que agrupa, suma o cuenta por categorías
tabulación
posición fija en la regla a la que salta el texto al pulsar la tecla Tab
tarjeta gráfica
componente que procesa las imágenes y las envía al monitor
transición
efecto al pasar de una diapositiva a la siguiente
vista Moderador
vista que solo ve quien presenta: diapositiva actual, siguiente, notas y tiempo
vistas
formas de ver y trabajar una presentación
