Apartado 7.2

Expresiones algebraicas

El lenguaje algebraico usa letras para representar números desconocidos o que pueden variar. Las letras se llaman variables.

Ejemplo. Del lenguaje común al algebraico
Un número\(x\)
El doble de un número\(2x\)
Un número más 5\(x + 5\)
La mitad de un número\(\dfrac{x}{2}\)
El cuadrado de un número\(x^2\)
El número siguiente a \(x\)\(x + 1\)
El triple de un número menos 4\(3x - 4\)
El perímetro de un cuadrado de lado \(l\)\(4l\)

Entre un número y una letra no se escribe el signo de multiplicar: \(3 \cdot x = 3x\).

  4. La suma de dos números consecutivos.
  5. El precio de \(n\) cuadernos a 2 € cada uno.
📖 Valor numérico

El valor numérico de una expresión algebraica es el resultado de sustituir las letras por números y hacer las operaciones.

Ejemplo. Valor numérico

Valor numérico de \(3x - 2\) para \(x = 4\): \(3 \cdot 4 - 2 = 10\).

Valor numérico de \(x^2 + 2x\) para \(x = -3\): \((-3)^2 + 2 \cdot (-3) = 9 - 6 = 3\).
