Apartado 2.1

Definición

Los números enteros forman un conjunto cerrado para las operaciones suma, resta y multiplicación. Esto significa que si realizas cualquiera de estas operaciones con dos números enteros el resultado también será entero. Sin embargo, al intentar repartir (dividir) esto ya no se cumple. Hay divisiones que dan exactas como 8 entre 2 y otras que no dan exactas como 8 entre 3.

Para poder efectuar repartos necesitamos ampliar los números enteros añadiendo otro conjunto y así formar el conjunto de los números fraccionarios o números racionales.

📖 Números naturales, enteros y racionales
  • \(\mathbb{N} = \{1,2,3,4,5,6,\ldots\}\)
  • \(\mathbb{Z} = \{\ldots,-4,-3,-2,-1,0,1,2,3,4,\ldots\}\)
  • \(\mathbb{Q} = \left\{\ldots,-\dfrac{4}{3},\dfrac{3}{10},\dfrac{6}{2},\dfrac{1}{7},\dfrac{9}{100},\ldots\right\}\)

Las dos partes de una fracción se denominan numerador y denominador. Las fracciones representan el cociente (división) entre dos números.

📖 Partes de una fracción

  • \(\dfrac{a}{b}\)

  • \(a\) es el numerador y representa el número de partes que se «seleccionan»
  • \(b\) es el denominador y representa el número de partes iguales en las que se divide la unidad.
Ejemplo. Ejemplos de fracciones
\(\dfrac{3}{8}\)\(\dfrac{7}{8}\)\(\dfrac{3}{4}\)\(\dfrac{7}{5}\)

Existen algunas expresiones que se utilizan al describir las fracciones y es muy importante conocer.

📖 Fracción propia e impropia
  • Fracción propia: el numerador es menor que el denominador

  • \(\dfrac{2}{3},\dfrac{7}{10}\)

  • Fracción impropia: el numerador es mayor que el denominador

  • \(\dfrac{4}{3},\dfrac{43}{10}\)

Simplificar una fracción es la operación de buscar fracciones equivalentes con términos menores. Cuando ya no se puede simplificar más se llama fracción irreducible. La búsqueda de fracciones equivalentes se realiza dividiendo por el mismo valor numerador y denominador.

Ejemplo. Proceso de simplificar una fracción

\(\dfrac{48}{72} \xrightarrow{:2} \dfrac{24}{36} \xrightarrow{:2} \dfrac{12}{18} \xrightarrow{:2} \dfrac{6}{9} \xrightarrow{:3} \dfrac{2}{3}\)

La operación contraria a simplificar se denomina amplificar una fracción y consiste en multiplicar ambos términos por un número en lugar de dividir. Para poder comparar fracciones o para poder sumarlas es necesario que todas tengan el mismo denominador. Se buscará una fracción amplificada en la que el denominador común sea el mínimo posible.

Ejemplo. Proceso de buscar fracciones con común denominador

\(\dfrac{3}{4},\dfrac{5}{2},\dfrac{2}{3},\dfrac{5}{6} \; \to \; m.c.m.(4,2,3,6)=12 \; \to \; \dfrac{9}{12},\dfrac{30}{12},\dfrac{8}{12},\dfrac{10}{12}\)
