Propiedades de las potencias

La potencia es la operación que surge naturalmente como una repetición de multiplicaciones, del mismo modo que la multiplicación consiste en una repetición de sumas. En esta unidad vamos a trabajar con ellas, pero será importante recordar las propiedades cuando tengamos que operar monomios o resolver ecuaciones exponenciales.

Comenzamos con propiedades que afectan a la multiplicación y división. Es importante tener en cuenta que no pueden aplicarse a la suma.

📖 Propiedades de las potencias I
  1. \(a^m\cdot a^n=a^{m+n}\)
  2. \(a^m: a^n=a^{m-n}\)
  3. \(\left( a^m \right) ^n = a^{m\cdot n}\)
  4. \(( a\cdot b\cdot c ) ^m=a^m\cdot b^m\cdot c^m\)
  5. \(a^0=1\)
  6. \(a^1=a\)
⚠️ ¡Las propiedades no sirven para sumar!

\(2^3\cdot 2^2=2^5\), pero \(2^3+2^2=8+4=12\), que no es \(2^5=32\). Las sumas y restas de potencias se calculan haciendo primero cada potencia.

Las potencias de exponente negativo se pueden convertir en una inversión entre denominadores y numeradores. De esta forma lo que está "arriba" pasa a estar "abajo" y viceversa.

📖 Propiedades de las potencias II
  1. \(a^{-m} =\dfrac{1}{a^m}\)
  2. \(\left( \dfrac{a}{b} \right) ^n = \dfrac{a^n}{b^n}\)
  3. \(\left( \dfrac{a}{b} \right) ^{-n} = \left( \dfrac{b}{a} \right) ^n = \dfrac{b^n}{a^n}\)
⚠️ ¡El exponente negativo no cambia el signo!

\(2^{-3}\) no es \(-8\) ni \(-6\): es el inverso de \(2^3\), es decir, \(2^{-3}=\dfrac{1}{2^3}=\dfrac{1}{8}\).
