Apartado 1.5

Números enteros

Los números naturales (\(\mathbb{N}\)) sirven para contar, pero no permiten expresar situaciones como una temperatura bajo cero, una planta por debajo de la calle o una deuda. Para ello se usan los números negativos.

📖 Números enteros
  • \(\mathbb{N} = \{1,2,3,4,5,\ldots\}\)
  • \(\mathbb{Z} = \{\ldots,-3,-2,-1,0,1,2,3,\ldots\}\)
  • Los números enteros son los naturales (enteros positivos), el 0 y los enteros negativos.

Los números enteros se representan en la recta numérica. Los positivos se colocan a la derecha del 0 y los negativos a la izquierda, a la misma distancia entre cada número y el siguiente.

📖 Opuesto y valor absoluto
  • El opuesto de un número es el que está a la misma distancia del 0 pero al otro lado: \(\text{op}(5)=-5\) y \(\text{op}(-14)=14\). El opuesto de 0 es 0.
  • El valor absoluto de un número es su distancia al 0. Siempre es positivo o cero: \(|-7|=7\) y \(|7|=7\).

Para ordenar números enteros basta recordar que en la recta un número es mayor cuanto más a la derecha está:

  • Cualquier número positivo es mayor que cualquier negativo.
  • Entre dos negativos es mayor el que tiene menor valor absoluto: \(-3>-8\).
Ejemplo. Ordenación de números enteros

\(-12 < -8 < -|-2| < 0 < 1 < 7 < |-10| < 19\)

1.5.1

Ordena de menor a mayor: \(-10\), \(8\), \(0\), \(1\), \(|-2|\), \(-15\), \(-|-4|\), \(-1\).
