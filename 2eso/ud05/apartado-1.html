Apartado 5.1

Patrones y lenguaje algebraico

Muchas situaciones siguen una regla que se repite. Si descubrimos la regla podemos calcular cualquier término sin tener que dibujarlos o contarlos todos.

Ejemplo. Un patrón con palillos

Para formar 1, 2 y 3 cuadrados se usan 4, 7 y 10 palillos. Cada cuadrado nuevo añade 3 palillos. Para \(n\) cuadrados hacen falta \(3n+1\) palillos. Con 50 cuadrados: \(3\cdot 50+1=151\) palillos.

El lenguaje algebraico utiliza letras para representar números desconocidos o que pueden variar. A esas letras se les llama variables o incógnitas.

📖 Del lenguaje natural al algebraico
Un número\(x\)
El doble de un número\(2x\)
El triple de un número menos cinco\(3x-5\)
La mitad de un número\(\dfrac{x}{2}\)
El cuadrado de un número\(x^2\)
Dos números consecutivos\(x,\;x+1\)
Un número par\(2n\)
Un número impar\(2n+1\)
5.1.1

Traduce al lenguaje algebraico:

  1. El triple de un número más su mitad.
  2. La edad de Ana dentro de 5 años, si ahora tiene \(x\) años.
  3. El precio de \(n\) entradas de 7 € más 2 € de gastos de gestión.
  4. La suma de tres números consecutivos.
📖 Expresión algebraica y valor numérico
  • Una expresión algebraica es una combinación de números y letras unidos por operaciones: \(3x^2-5x+1\).
  • El valor numérico de una expresión es el número que se obtiene al sustituir las letras por números y operar.
Ejemplo. Valor numérico

Valor numérico de \(3x^2-5x+1\) para \(x=-2\):

\(3\cdot(-2)^2-5\cdot(-2)+1=3\cdot 4+10+1=23\)
