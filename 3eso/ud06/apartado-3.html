Apartado 6.3

Ecuaciones de segundo grado

📖 Ecuación de segundo grado

Una ecuación de segundo grado se puede escribir en la forma general

\[ax^2 + bx + c = 0 \qquad (a \neq 0)\]

Si \(b = 0\) o \(c = 0\) se dice que es incompleta.

Ecuaciones incompletas

Las ecuaciones incompletas se resuelven sin fórmula:

📖 Ecuaciones incompletas

  • Si \(b = 0\): \(\; ax^2 + c = 0\). Se despeja \(x^2\) y se hace la raíz cuadrada, que da dos soluciones opuestas (o ninguna, si el número es negativo).

    \[x^2 - 49 = 0 \;\Rightarrow\; x^2 = 49 \;\Rightarrow\; x = \pm 7\]

  • Si \(c = 0\): \(\; ax^2 + bx = 0\). Se saca factor común \(x\). Un producto vale 0 si alguno de sus factores vale 0, así que una solución es siempre \(x = 0\).

    \[3x^2 + 12x = 0 \;\Rightarrow\; 3x(x + 4) = 0 \;\Rightarrow\; x = 0, \ x = -4\]
⚠️ No dividas entre \(x\)

Si en \(3x^2 + 12x = 0\) dividimos entre \(x\), queda \(3x + 12 = 0\) y solo obtenemos \(x = -4\): se pierde la solución \(x = 0\). Hay que sacar factor común. Y en \(x^2 = 49\) no olvides la solución negativa: \(x = \pm 7\).

Ecuaciones completas

📖 Fórmula de la ecuación de segundo grado

Las soluciones de \(ax^2 + bx + c = 0\) son:

\[x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]

El número \(\Delta = b^2 - 4ac\) se llama discriminante y decide cuántas soluciones hay:

  • \(\Delta > 0\): dos soluciones distintas.
  • \(\Delta = 0\): una solución (doble).
  • \(\Delta < 0\): ninguna solución real.
Ejemplo. Ecuación completa

\(x^2 - 5x + 6 = 0\), con \(a = 1\), \(b = -5\), \(c = 6\):

\[x = \dfrac{5 \pm \sqrt{25 - 24}}{2} = \dfrac{5 \pm 1}{2} \;\Longrightarrow\; x_1 = 3, \quad x_2 = 2\]

Comprobación: \(3^2 - 5 \cdot 3 + 6 = 0\) y \(2^2 - 5 \cdot 2 + 6 = 0\).

Si la ecuación no está en forma general, primero hay que quitar paréntesis y denominadores y pasar todos los términos a un miembro, igualando a cero.
