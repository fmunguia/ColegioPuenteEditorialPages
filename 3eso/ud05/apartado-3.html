Apartado 5.3

Polinomios

📖 Polinomio

Un polinomio es una suma de monomios no semejantes, que se llaman términos. El grado del polinomio es el mayor de los grados de sus términos, y el término independiente es el que no tiene parte literal.

\[P(x) = 2x^3 - x + 4\]

es un polinomio de grado 3 con término independiente 4. Se suelen escribir ordenados de mayor a menor grado.

Suma y resta de polinomios

Para sumar polinomios se suman los términos semejantes. Para restarlos, se suma al primero el opuesto del segundo, es decir, se cambian de signo todos los términos del segundo.

Ejemplo. Suma y resta

\(P(x) = 2x^3 - x + 4 \qquad Q(x) = x^2 + 3x - 1\)

\[\begin{aligned} P(x) + Q(x) &= 2x^3 + x^2 + (-x + 3x) + (4 - 1) = 2x^3 + x^2 + 2x + 3 \\ P(x) - Q(x) &= 2x^3 - x + 4 - x^2 - 3x + 1 = 2x^3 - x^2 - 4x + 5 \end{aligned}\]
⚠️ Al restar cambian de signo todos los términos

\(P(x) - Q(x)\) no es \(2x^3 - x + 4 - x^2 + 3x - 1\). El signo menos afecta a todo \(Q(x)\): se cambian de signo todos sus términos, \(-(x^2 + 3x - 1) = -x^2 - 3x + 1\).

Multiplicación de polinomios

Para multiplicar dos polinomios se multiplica cada término del primero por cada término del segundo (propiedad distributiva) y después se agrupan los términos semejantes.

Ejemplo. Producto de polinomios
\[\begin{aligned} (2x - 1)(x^2 + 3x - 2) &= 2x^3 + 6x^2 - 4x - x^2 - 3x + 2 \\ &= 2x^3 + 5x^2 - 7x + 2 \end{aligned}\]
5.3.1

Dados \(P(x) = x^2 - 4x + 3\) y \(Q(x) = 2x - 5\), calcula \(P(x) - Q(x)\) y \(P(x) \cdot Q(x)\).

División de un polinomio entre un monomio

Para dividir un polinomio entre un monomio se divide cada término del polinomio entre el monomio.

\[(12x^4 - 8x^3 + 4x^2) : 4x^2 = 3x^2 - 2x + 1\]
